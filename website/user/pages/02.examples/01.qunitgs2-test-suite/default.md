It uses a more complicated set up in order to manage many more tests.  You can [load the test results live here](https://script.google.com/macros/s/AKfycbxGNuNyR-pec75X_whqf56rkoi8-8ne5aeK8bdctR-uyq5Wjwht/exec) to make sure the library is still working.  **Tests can take a long time to complete**- like 2 minutes- so be patient.
